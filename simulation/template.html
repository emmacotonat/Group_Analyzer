1. Coneixement manifestat i corroborat

La percebuda conserva el contingut atribuït. La cobertura resumeix sobre quants ítems es manifesta coneixement. L’efectiva s’operacionalitza com a corroboració respecte d’un criteri, aquí una autodescripció sintètica.

Matriu de coneixement

Fila = qui respon · columna = persona sobre qui respon. Blau més intens = valor més alt. Gris = no definit o diagonal. Cada casella inclou el valor en passar-hi el cursor.

Ser consultat i ser conegut

El generador afavoreix les consultes a P01 i en redueix deliberadament la precisió biogràfica. Aquest patró és una demostració de representació, sense valor de descobriment empíric.

4. Què mostra i què queda pendent

Descomposició descriptiva i límit del SRM

El fitxer de dades inclou residus d’un ajust additiu per observador i persona concernida, estimat per mínims quadrats iteratius. No estima components de variància del SRM, no separa relació i error, i no produeix significació estadística. El SRM formal requereix decisions de mesura i estimació addicionals.

Reproducció i exportació

La llavor i el generador determinen totes les dades. El codi Python no necessita dependències externes. Executa python simulation/generate.py i python -m unittest discover -s simulation -p 'test_*.py' des de l’arrel del repositori.

La simulació no valida el concepte, no prediu conflictes i no és una anàlisi de potència. No hi ha resultats de camp ni dades de cap cau. Una aplicació real requerirà protocol ètic, pilot i protecció de les persones.
